10,000 line segments

A 10,000-vertex line with vertex colours, blending towards a second random shape.

Original: three.js example webgl_buffergeometry_lines (MIT, © three.js authors). Ported to WAMR3D by changing the library.

What changed besides the import
  • No morph targets yet: the blend writes the position attribute each frame (needsUpdate) instead of morphTargetInfluences.
  • new Timer( performance.now() ) and timer.update( timestamp ) instead of timer.connect( document ).
