500,000 points

Half a million coloured points in one BufferGeometry, rotating in fog.

Original: three.js example webgl_buffergeometry_points (MIT, © three.js authors). Ported to WAMR3D by changing the library.

What changed besides the import
  • color.setRGB( r, g, b, SRGBColorSpace ) → setRGB( r, g, b ).convertSRGBToLinear(), the same colour.
  • Points are one pixel in both WebGPU renderers; size has no effect there.
